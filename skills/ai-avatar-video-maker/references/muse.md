# Muse 分段与尾帧参考

本项目不包含 Muse 自动接口或代付能力。`build_tasks.py` 生成离线任务；由人或可操作电脑的 Agent 将其中提示和真实图片附件交给 Muse。实际账号、时长、费用、输入方式及输出参数以当前界面为准。

1. 第一段先用角色参考图，生成并实际听审、审看。
2. 观察片尾约 0.5–1 秒，选出适合衔接的状态；既注意台词，也看眼睛、嘴、头肩、镜头与背景。
3. `handoff.py` 先导出独立保留视频，再从该视频提取真正的末帧，生成绑定这张图片的新任务清单。检查它是睁眼还是闭眼，以及是否完整保留讲话。
4. 把图片**实际作为附件**提交下一段；继续保持同一人物、视线、服装、头肩位置、机位与光线，不把文件名或仅提到图片当作上传证明。它仍只是参考，不能声称首帧被硬锁定。
5. 检查新片的首帧与上一段末帧以及整段人物，发现不一致要按用户已授权的范围处理。每段使用一个真实源文件和独立保存路径。
6. 导入结果时，`import_muse.py` 校验图片哈希及视频；用户必须自行审查才可标记 `approved`。在 `assemble.py` 用接力工具给出的 `--keep-frames` 维持相同选点。重新编码后需检查实际最终接点。

当原声有错且准备另配音，要把识别误差与实际错词分别记录。whisper-cli 比稿分数只是辅助证据，不代表真实发音、口型或人物身份通过。原音有噪声、音乐或不同音色时，直接串接可能引入听感跳变；需单独处理，不承诺已自动产生连续底音。
